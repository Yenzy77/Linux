# Shared components

This phase reuses illogical-impulse's Matugen output. The SDDM integration owns the shared media input helpers consumed by the Limine renderer. Keep the installed helper path and interface stable until both consumers can migrate together. Future shared components belong here after at least two profiles have a demonstrated need.

The [optional Steam Material adapter](applications/steam-material/README.md) records the reference Matugen template and supports manual opt-in.
