# Repository instructions

- Phase 1 covers CachyOS, Hyprland, and illogical-impulse. Follow the roadmap for future scope.
- Treat every tracked file and Git object as public. Capture individual allowlisted files. Keep private paths, credentials, user IDs, machine IDs, disk UUIDs, generated boot entries, logs, and local backups outside Git.
- Use English for scripts, documentation, and commits. Record upstream source and licensing before importing material. Preserve upstream notices.
- Use local templates for host-specific settings. Keep privileged installation separate and explicit. Validate paths, ownership, and permissions and preserve recovery behavior.
- Run syntax checks, local publication validation, and representative isolated tests. Review the complete staged diff and every new Git object before pushing.
- Never test with personal browser data or Keyring contents. Use check-only commands. Never change the running reference desktop during repository validation.
- Keep examples and documentation consistent with supported behavior. State what remains untested.
